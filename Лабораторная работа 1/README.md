# ЛР № 1. ЛП-модель закупки упаковки (вариант 11)

Параметры варианта: N = 1, Q = 1 (группа 517), Y = 26.
V = 1 + ((17·1 + 7·1 + 26) mod 20) = **11**, seed = 10000 + 100·1 + 1 = **10101**.

Задача: закупка 4 видов упаковки у 5 поставщиков с оптовыми ценами, минимум затрат.

## Установка

Нужен Python 3.12.

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Запуск

```bash
.venv/bin/python run.py
```

Команда заново генерирует данные, решает все модели, выполняет проверку и перезаписывает `results/`. Сводка печатается в консоль и сохраняется в `results/summary.json`. Время работы — несколько секунд.

## Генерация данных

`src/generate_data.py`, генератор `numpy.random.default_rng(10101)`. Базовые параметры упаковки (спрос, цена, масса, объём, норма брака) заданы в коде и выбраны правдоподобно. Случайно генерируются:

- мощности и лимиты логистики: доли из распределения Дирихле (α = 12) от 120 % потребности в часах и 140 % потребности в перевозке;
- ценовой уровень поставщика: U(0,90; 1,12), разброс по паре ±3 %;
- нормы часов: базовая норма × U(0,8; 1,25);
- брак: норма × (0,8 + 3·(1 − ценовой множитель) + N(0; 0,12)), поэтому дешёвые поставщики в среднем дают больше брака;
- суммарная ширина ступеней: U(0,55; 0,80) от спроса, деление 30/40/30 %;
- скидка каждой следующей ступени: U(4 %; 8 %);
- по одному случайному поставщику на вид упаковки не делает предложения (фактически закрыто 4 пары из 20).

Склад: 112 % от базовой потребности в объёме. Константа 0,8 в формуле брака подобрана вручную: при значении 1,0 базовая задача несовместна (норму брака по гофрокоробу выполнял только один маломощный поставщик).
