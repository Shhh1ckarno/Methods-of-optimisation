# ЛР № 2. Перераспределение пустых контейнеров между портами (вариант 11)

Параметры варианта: N = 1, Q = 1 (группа 517), Y = 26.
V = 1 + ((17·1 + 7·1 + 26) mod 20) = **11**, seed = 10000 + 100·1 + 1 = **10101**.

Задача: поток минимальной стоимости в сети из 6 портов и 18 морских дуг. Порты с избытком пустых контейнеров отдают их портам, где контейнеров не хватает.

## Установка

Нужен Python 3.12.

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Запуск

```bash
.venv/bin/python run.py
```

Команда заново генерирует данные, решает все модели, выполняет проверку, строит графики и перезаписывает `results/`. Сводка печатается в консоль и сохраняется в `results/summary.json`. Время работы около 10 секунд.

## Генерация данных

`src/generate_data.py`, генератор `numpy.random.default_rng(10101)`.

- Координаты 6 портов равномерно в прямоугольнике 1000 × 600 км.
- Три случайных порта с нехваткой U(150; 320) TEU, округление до 10. Три порта с избытком, суммарно 112 % нехватки, доли из распределения Дирихле (α = 6).
- Линии: минимальное остовное дерево по расстояниям плюс ближайшие пары до 9 линий, каждая линия дает две дуги.
- Стоимость дуги 40 + 0,22 · расстояние · U(0,85; 1,15) долл./TEU, пропускная способность U(100; 300) TEU в неделю, округление до 10.
- Для дополнительного задания размер слота на рейсе выбирается из {40, 50, 60} TEU. Стоимость рейса равна 60 % стоимости перевозки полного слота, оставшиеся 40 % — переменная стоимость за TEU. Поэтому при полной загрузке рейсов цена TEU совпадает с ЛП.
- Аренда контейнера в сценарии с дефицитом стоит 600 долл./TEU.

Диапазон пропускных способностей 100–300 подобран вручную. При 60–220 сеть была настолько тесной, что несовместными оказывались все стрессовые сценарии.

`results/greedy_benchmark.csv` строится тем же генератором с seed от 10102 до 10301.
